# Draft member inference contract

The [cross-repository proposal](https://github.com/true-line/agent-bot-platform/discussions/103) is under review. The candidate uses the existing assigned HQ member socket and member binding. There is no configured production provider. The trusted provider plugin's authorization callback must check the current bound runtime, Equip handle, task, destination, operation and any cost ceiling against HQ policy. Client-supplied identifiers select an operation for that check. The callback decides authority before the external operation starts. The client sends no URL, provider secret, price, or authority override.

`inference.models` uses the ordinary request and result envelope and returns a list of model identifiers. `inference.responses` requires `response: "stream"` and adds a model identifier and a text input. The broker returns correlated `response.output_text.delta` chunks and then either a refusal or one result with input and output token usage. Existing unary requests keep their framing. Responses are limited to 4,096 chunks and 8 MiB total. Both operations have a two-minute deadline starting when HQ begins servicing the frame, before broker dispatch and authorization. Time spent queued behind earlier requests is outside that deadline. The SDK client supports a synchronous chunk callback and closes the bound connection on cancellation. It never replays a failed inference request.

HQ stops waiting on authorization and drops its revocation hook on disconnect, deadline or device revocation, even if the callback is still pending. Trusted authorization and provider callbacks receive the abort signal and must propagate it to their I/O. A host deadline can end signal-aware I/O and result delivery. The vendor may already have accepted or charged for a dispatched request. Before invoking a Responses producer, HQ reserves the authorized cost ceiling and persists an `outcome_unknown` operation. A valid terminal outcome settles measured cost and records completion. Aborted or lost operations retain their recorded uncertainty and their current reservation. The durable operation record prevents replay of the same authorized Soul, task and operation, including after restart.

Deployment requires a decision approving these private member envelope extensions and provider routing rules, including the scope and units of a granted cost ceiling, provider eligibility and reconciliation of incomplete outcomes. The SDK budget accounts are in memory. Until HQ can reconstruct or reconcile unresolved reservations and completed spend across restart, the candidate cannot enforce a durable aggregate ceiling. Production work also needs the Identity credential operation, actual vendor cancellation and cost verification, compatible Codex transport, and signed launch qualification. The synthetic fixture covers this draft behavior only.
