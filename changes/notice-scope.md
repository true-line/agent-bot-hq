HQ can bind an owner-configured notice harness and repository to an exact
accepted runtime assignment. Each runtime persists that scope or explicit
absence. A host-only guard rechecks liveness, epoch, generation, enrollment
and unchanged owner policy before a trusted mailbox effect. Restart and
configuration changes cannot give old runtimes new scope. Ordinary admission
continues without notice scope.

The shared notice contract, comms mailbox query and legacy shim remain
separate integration work; no member notice operation or production rollout
is enabled here.

Refs #128; platform PDR-0062.
